# Currículo em HTML

Comecei este currículo como um trabalho da faculdade, no curso de Análise e Desenvolvimento de Sistemas. Depois resolvi continuar e transformar em algo de verdade: hoje é o currículo que eu uso, com versão online que funciona no computador e no celular, e que também pode ser impressa ou salva em PDF.

**Ver online:** https://wezeley.github.io/CurriculoHTML

## O que tem aqui

- `index.html`: o currículo inteiro, com o CSS dentro do próprio arquivo
- `Wesley.jpg`: minha foto

## O que eu pratiquei

- Layout com CSS Grid e Flexbox
- Versão para celular com `@media`
- Versão para impressão em A4 com `@media print`
- Publicação no GitHub Pages

## Como gerar o PDF

Abra o site no Chrome, aperte Ctrl + P e escolha "Salvar como PDF". O layout já está pronto para 2 páginas A4.
